# 世界时间可视化网页项目需求文档

> **本文档描述的是目标态，不是现状。** 其中大量功能尚未实现，以代码和 `CLAUDE.md` 为准；已知差距见 `docs/当前问题.md`。
>
> 基准时区已由北京时间改为可配置的 `BASE_ZONE`（当前为洛杉矶，`America/Los_Angeles`）。下文凡是“北京时间”作为基准的地方，都应理解为“基准时间”；`beijingTime` 字段现名 `baseTime`。

## 1. 项目概述

### 1.1 项目名称
世界时间可视化网页应用

### 1.2 项目目标
开发一个交互式的世界时间可视化网页，能够直观地显示全球各时区的时间变化以及地球的昼夜光照分布。

### 1.3 核心特色
- 以北京时间为基准的全球时间显示
- 实时太阳光照可视化
- 滚动交互改变时间
- 直观的地球仪/地图界面

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 世界时钟显示
- **多时区显示**: 同时显示至少12个主要城市的时间
  - 北京、东京、悉尼、新德里、迪拜、莫斯科
  - 柏林、伦敦、纽约、洛杉矶、芝加哥、圣保罗
- **时间格式**: 支持24小时制和12小时制切换
- **日期显示**: 显示每个时区的当前日期
- **时差显示**: 显示与北京时间的时差

#### 2.1.2 太阳光照可视化
- **昼夜分界线**: 实时计算并显示晨昏线
- **光照渐变**: 展现日出日落的渐变效果
- **季节变化**: 考虑地球倾斜角度的季节性变化
- **极昼极夜**: 正确显示极地地区的特殊现象

#### 2.1.3 时间控制交互
- **滚动控制**: 鼠标滚轮或触摸滑动改变北京时间
- **时间范围**: 支持前后24小时的时间调整
- **步进设置**: 支持分钟级、小时级的时间步进
- **时间重置**: 一键回到当前真实时间

#### 2.1.4 地球可视化
- **3D地球仪**: 使用Three.js渲染3D地球
- **地图投影**: 可选2D世界地图视图
- **城市标记**: 重要城市的位置标记
- **自转动画**: 可选的地球自转效果

### 2.2 增强功能

#### 2.2.1 用户自定义
- **城市添加**: 用户可添加关注的城市
- **主题切换**: 日间/夜间主题模式
- **语言切换**: 中文/英文界面

#### 2.2.2 信息展示
- **天文信息**: 显示日出日落时间
- **UTC时间**: 显示协调世界时
- **时区信息**: 显示时区缩写和偏移

## 5. 实现细节

### 5.1 滚动控制实现
```javascript
// 滚动事件处理

  const delta = event.deltaY;
  const timeOffset = delta * 0.1; // 滚动灵敏度

```

### 5.2 性能优化
- **节流控制**: 滚动事件节流，避免过度计算
- **虚拟化**: 大量城市数据的虚拟滚动
- **缓存机制**: 太阳位置计算结果缓存
- **Web Workers**: 复杂计算移至后台线程

### 5.3 数据更新策略
- **实时模式**: 每秒更新一次
- **历史模式**: 仅在用户交互时更新
- **批量更新**: 多个时区时间一次性计算

## 7. 技术难点与解决方案

### 7.1 太阳光照精确计算
- **难点**: 天文算法复杂，需考虑地球倾斜、椭圆轨道等因素
- **解决**: 使用成熟的天文计算库，如SunCalc.js

### 7.2 3D渲染性能
- **难点**: 地球纹理和光照效果对性能要求高
- **解决**: LOD技术、纹理压缩、WebGL优化

### 7.3 时区数据准确性
- **难点**: 时区规则复杂，夏令时变化频繁
- **解决**: 使用IANA时区数据库，定期更新

## 8. 预期效果

用户打开网页后，将看到一个美观的3D地球，实时显示当前的昼夜分布。左侧列表显示世界主要城市的时间。当用户滚动鼠标滚轮时，能够流畅地"穿越时间"，观察全球时间的变化和太阳光照的移动，为用户提供直观且富有教育意义的时间可视化体验。
