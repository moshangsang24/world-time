# 世界时间可视化

在一张世界地图上同时看各城市的当地时间和全球昼夜分布。以一个城市的时间为基准（默认洛杉矶，可切换），可以把时间前后拨动 24 小时，观察各时区时间和晨昏线的变化。

## 功能

- **2D 世界地图**：真实海岸线与国界（Natural Earth 1:110m），等距圆柱投影。
- **昼夜分布**：按太阳高度角实时计算夜面，带曙暮光渐变和晨昏线；太阳画在真实直射点。
- **世界时钟**：侧栏显示各城市的当地时间、日期、星期和相对基准的时差，白天 / 夜晚用卡片底色区分；可切换数字或钟表样式；选中城市时显示当地日出日落。
- **时间控制**：滚轮、键盘、滑块或快捷按钮，在当前时刻前后 24 小时内移动。
- **城市管理**：在线搜索并添加世界上任意城市，也可以从 18 个常用城市里选；列表保存在浏览器本地。
- **主题**：浅色 / 深色，地图配色随主题切换。

## 快速开始

需要 Node.js 18 或更高版本。

```bash
npm install
```

```bash
npm run dev
```

然后打开 `http://localhost:3000`。

## 操作

| 操作 | 效果 |
|---|---|
| 在地图或时间控制区滚动滚轮 | 时间前进 / 后退，每格 1 分钟 |
| `←` / `→` | 时间后退 / 前进 1 分钟 |
| `空格` | 暂停 / 恢复实时 |
| `Home` | 回到当前时间并恢复实时 |
| 拖动底部滑块、点快捷按钮 | 跳到指定偏移；“现在”恢复实时 |
| 点击地图上的城市或侧栏卡片 | 选中城市，两边同步高亮；再点一次取消 |
| 卡片上的“设为基准” / “×” | 切换基准城市 / 移除城市（基准城市不能移除） |

拨动时间后进入暂停状态，偏移以暂停那一刻为起点计算。

## 基准时区

默认以洛杉矶为基准。出差时有两种切换方式：

- 在城市卡片上点“设为基准”（桌面端悬停时出现，手机上先点一下卡片）。
- 齿轮 → 设置 → 基准城市；或打开“跟随设备时区”，电脑或手机自动改时区后基准也跟着变。

切换后顶栏、时差、“明天/昨天”、地图上的基准红圈都会跟着变。设置保存在浏览器本地。代码里的默认值是 `src/data/constants.ts` 的 `DEFAULT_BASE_CITY_ID`。

## 技术栈

React 18、TypeScript、Vite 5、Zustand、Luxon、Tailwind CSS。城市搜索使用 [Open-Meteo 地理编码接口](https://open-meteo.com/en/docs/geocoding-api)，搜索词会发送给该服务；添加后的城市保存在本地，显示时间不再联网。地图数据来自 `world-atlas`，用 `topojson-client` 解码后画在 canvas 上。太阳位置用 NOAA 算法计算，测试里用 `suncalc` 做对照。

```
src/
├── components/
│   ├── common/          通用组件
│   ├── layout/          页面布局、顶栏、侧栏
│   ├── time/            世界时钟、城市卡片、时间滑块
│   └── visualization/   2D 地图（map2d/ 下是各绘制层）
├── hooks/               时间状态、太阳位置、滚轮与键盘控制
├── store/               Zustand store
├── utils/               时间、太阳位置、坐标计算
├── data/                城市数据与常量
└── types/               类型定义
```
