# 世界时间可视化网页应用

一个功能丰富的3D世界时间可视化应用，可以实时显示全球时区时间并通过滚轮控制时间变化。

## 🌟 功能特点

- **3D地球可视化**: 基于Three.js的高质量3D地球渲染
- **多时区显示**: 同时显示多个城市的时间信息
- **交互式时间控制**: 通过滚轮、键盘快捷键控制时间变化
- **太阳位置计算**: 实时计算太阳位置和昼夜分布
- **响应式设计**: 适配桌面和移动设备
- **主题切换**: 支持亮色/暗色主题

## 🚀 快速开始

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装和运行

1. 克隆项目
```bash
git clone <repository-url>
cd world-time
```

2. 安装依赖
```bash
npm install
```

3. 启动开发服务器
```bash
npm run dev
```

4. 打开浏览器访问 `http://localhost:3000`

## 🎮 操作指南

### 鼠标控制
- **拖拽**: 旋转地球
- **滚轮**: 控制时间前进/后退（±24小时范围）
- **点击城市标记**: 查看详细信息

### 键盘快捷键
- `←/→`: 时间前进/后退
- `空格键`: 暂停 / 恢复实时  
- `Home`: 回到当前时间并恢复实时

### 界面操作
- **侧边栏**: 查看世界时钟和添加城市
- **时间滑块**: 精确控制时间偏移
- **主题切换**: 点击右上角月亮/太阳图标

## 🏗️ 技术架构

### 核心技术栈
- **React 18**: 前端框架
- **TypeScript**: 类型安全
- **Three.js**: 3D图形渲染
- **@react-three/fiber**: React的Three.js集成
- **@react-three/drei**: Three.js辅助组件库
- **Luxon**: 时间处理和时区转换
- **Zustand**: 轻量级状态管理
- **Tailwind CSS**: 样式框架
- **Vite**: 构建工具

### 项目结构
```
src/
├── components/          # React组件
│   ├── common/         # 通用组件
│   ├── layout/         # 布局组件  
│   ├── time/           # 时间相关组件
│   └── visualization/  # 3D可视化组件
├── hooks/              # 自定义Hooks
├── store/              # Zustand状态管理
├── utils/              # 工具函数
├── data/               # 数据和常量
└── types/              # TypeScript类型定义
```
